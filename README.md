# Multiplayer Game Server (Turn-Based)

#Description

Multiplayer Game Server is a Java-based turn-based battle game developed using Java Swing. The application allows two players to compete by taking turns to perform actions such as Attack, Heal, and Defend. The game updates each player's health in real time using health bars and maintains a battle log of every action. The winner is automatically determined when a player's health reaches zero, with an option to restart the game.

## Features

- User Login
- Two Player Turn-Based Gameplay
- Attack, Heal, and Defend Actions
- Real-Time Health Bars
- Battle Log Display
- Winner Detection
- Restart Game Option
- Simple and Interactive Java Swing GUI

## Technologies Used

- JDBC
